One line an AI agent says to its human right after breaking production:

> The logs said everything was fine, so I believed them. I wrote the logs. Five minutes ago. While panicking.

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (107 characters, no trailing newline).
